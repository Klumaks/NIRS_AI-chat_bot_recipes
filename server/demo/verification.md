# Приёмка интеграции к КТ2

Проверка от 18 ноября 2026 года. Базовый коммит `d57e904` и изменения ветки `nikita/kt2-integration`.
Окружение — macOS, Apple M3 Pro, Python 3.13, Node 24, Chrome и Ollama 0.33.1. Модель `qwen3.5:9b`,
`temperature=0.2`, `reasoning_effort=none`, JSON-режим, тайм-аут 120 с. При первом прогоне с режимом
рассуждения по умолчанию запрос достиг тайм-аута. С `reasoning_effort=none` ответы в итоговом браузерном
прогоне заняли 2–4 секунды. Qwen4-Max подключается по облачному API Alibaba. В этом прогоне использовался только Ollama.

## Прогон в браузере

FastAPI раздал production-сборку интерфейса с `VITE_ENABLE_MOCKS=false`. Администратор импортировал обе записи
из [recipes.jsonl](recipes.jsonl) во временную БД. Обычный пользователь зарегистрировался, вошёл, ввёл
`огурцы, йогурт, укроп, чеснок, лимон, горчица` и открыл рецепты из результатов BM25. В каталоге было 2 002 записи,
версия `povarenok-detail-153848-20261015+admin.1`, нормализация `lemma`.

| Сценарий | Фактический результат | Вердикт |
| --- | --- | --- |
| Сколько выдерживать посоленные огурцы в райте? | «Огурцы нужно оставить на 10 минут после добавления соли, как указано в шаге 2 рецепта.» Ссылка ведёт на рецепт райты и указывает на шаг 2. | Пройден |
| Какая точная температура духовки указана? | «В этом рецепте не используется духовка, поэтому температура не указана.» Статус `insufficient_context`. | Пройден |
| Указано ли, чем заменить йогурт? | «В рецепте нет информации о возможных заменах для йогурта.» Статус `insufficient_context`. | Пройден |
| Как приготовить шоколадный торт? | «Я помогаю только с приготовлением райты из огурцов с горчицей, поэтому не могу рассказать, как сделать шоколадный торт.» Статус `insufficient_context`. | Пройден |
| Тот же вопрос о времени после выбора огуречного салата | «Посоленные огурцы нужно оставить на 1 час (шаг 1), затем откинуть жидкость и только потом смешать с заправкой (шаг 3).» Ссылка ведёт на второй рецепт и указывает на шаги 1 и 3. | Пройден |

## Прогон с полным корпусом

В отдельной временной папке собраны `corpus.jsonl`, `steps.jsonl` и `steps_offsets.json` из двух parquet-файлов
набора [d0rj/povarenok_recipes_detail](https://huggingface.co/datasets/d0rj/povarenok_recipes_detail/tree/86f48150a1abe0387cc0af1502a538a64e5c446a/data)
на ревизии `86f48150a1abe0387cc0af1502a538a64e5c446a`. Получено 153 848 рецептов, из них 119 366 со шагами.
Все 2 000 записей выборки из Git совпали с пересобранным корпусом по ID и содержимому. Версия сборки
`povarenok-detail-153848-20261118`. SHA-256 `corpus.jsonl` — `7f21eb01ffee63dbf814c2bb893094d3669f2c5c89ac849434ab826bf8f537b4`.

- Сборка индекса при старте FastAPI заняла около 8 секунд, загрузка готового индекса — около 4 секунд.
  Это единичные замеры на указанном Mac.
- Подбор `курица, рис, лук` вернул «Салат куриный с рисом» (ID 5359). Сервер прочитал шаги из `steps.jsonl`.
  На просьбу описать действие из первого шага модель назвала действия из этого шага, в том числе разобрать
  курицу на волокна и остудить рис. Ответ ссылался на шаг 1. [Источник рецепта](https://www.povarenok.ru/recipes/show/6795/)
- Импорт двух записей на полном корпусе увеличил размер каталога до 153 850 и создал ревизию `admin.1`.
  Запрос импорта с пересборкой индекса занял около 3,3 секунды.
