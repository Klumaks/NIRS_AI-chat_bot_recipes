# НИРС: ИИ-чат-бот рецептов «ИИ-шеф»

«ИИ-шеф» помогает выбрать блюдо по имеющимся продуктам, отфильтровать варианты по КБЖУ и времени, открыть рецепт и задать вопросы при приготовлении. Веб-чат требует входа, поддерживает роли `user` и `admin`. Личные чаты сохраняются между входами до удаления с подтверждением.

В репозитории реализован **локальный фронтенд на HTTP-моках**. Аккаунты, данные рецептов и ответы учебные; настоящие FastAPI, RAG и LLM к нему ещё не подключены.

## Запуск фронтенда

Требуются Node.js 20.19+ либо 22.12+ и Corepack. В WSL выполнять команды внутри Ubuntu:

```bash
cd frontend
corepack pnpm install --frozen-lockfile
npm run dev
```

Открыть [http://localhost:5173](http://localhost:5173). Порт фиксирован. На странице входа открыть панель **«Демо · доступ и сценарии»**: там показаны учебные доступы пользователя и администратора. В той же панели находятся переключатели ошибок и сброс с подтверждением.

[Инструкция для преподавателя: все адреса страниц, доступы, сценарии и подключение FastAPI](spec/frontend-check.md).

Основные страницы: [вход](http://localhost:5173/login), [регистрация](http://localhost:5173/register), [чат](http://localhost:5173/chat), [аккаунты](http://localhost:5173/admin/users), [активность](http://localhost:5173/admin/activity). Административные страницы требуют учебной роли admin.

«Чат с ИИ-шефом» возвращает в последний открытый личный чат; «+ Новый подбор» открывает пустой экран для другого набора продуктов. Предыдущие чаты сохраняются. Подробности — в [инструкции](spec/frontend-check.md#кнопки-навигации).

## Учебные логины и пароли

Откройте [страницу входа](http://localhost:5173/login) и нажмите **«Демо · доступ и сценарии» в правом нижнем углу**. Перенесите email и пароль выбранной роли из панели в форму входа.

| Роль | Логин (email) | Пароль |
| --- | --- | --- |
| Пользователь | user@ai-chef.test | `DemoUser123!` |
| Администратор | admin@ai-chef.test | `DemoAdmin123!` |

Это публичные пароли только для HTTP-моков. Они сохраняются после перезагрузки и сброса демоданных. В панели есть кнопка «Копировать пароль». Аккаунты, созданные вами, используют заданный при создании пароль. Самостоятельная регистрация создаёт пользователя; другого администратора создаёт действующий admin.

## Моки и интеграция

Страницы работают через типизированный API-клиент с обычным fetch и credentials: include. Компоненты не импортируют фикстуры. В режиме разработки `VITE_ENABLE_MOCKS=true` динамически включает MSW до отрисовки; `false` обращается к серверу без возврата к фикстурам при ошибке. Префикс задаётся `VITE_API_BASE_URL`, по умолчанию /api/v1.

`npm run dev:api` отключает моки; для прокси на FastAPI задаётся `API_PROXY_TARGET`. Производственная сборка по умолчанию без моков. Переход на сервер и удаление загрузчика моков описаны в [инструкции](spec/frontend-check.md#переход-на-fastapi).

## Проверка существующего поиска

Команды выполняются отдельно, Python 3.10+, PowerShell:

```powershell
Set-Location 'D:\ai-chef\ai-chef'
python tests/test_rag.py
python -m rag.search query "курица рис" --mode stem --corpus data/sample_corpus.jsonl
```

Тестовый скрипт и CLI поиска на выборке ранее проверены. CLI при отсутствии индекса сохраняет его рядом с данными. Для основного режима лемматизации:

```powershell
python -m pip install -r requirements.txt
python -m rag.search query "курица рис" --corpus data/sample_corpus.jsonl
```

Без pymorphy3 режим lemma заменяется на stem; фиксируйте фактический режим. Подготовка полного корпуса — в [RAG](spec/tech/rag.md). При создании фронтенда поиск, корпус и индекс не изменялись; новый benchmark не проводился.
