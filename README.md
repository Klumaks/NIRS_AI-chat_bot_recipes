# НИРС: ИИ-чат-бот рецептов «ИИ-шеф»

«ИИ-шеф» помогает выбрать блюдо по имеющимся продуктам, отфильтровать варианты по КБЖУ и времени, открыть рецепт и задать вопросы при приготовлении. Целевой интерфейс — веб-чат с обязательными регистрацией и входом, ролями `user` и `admin`.

Первичный SDD к КТ1. Дата фиксации: **15.10.2026**. Документы различают существующие компоненты и целевое поведение; это не отчёт о готовом приложении.

## Проверка существующего поиска

Python 3.10+, PowerShell:

```powershell
Set-Location 'D:\ai-chef\ai-chef'
python tests/test_rag.py
python -m rag.search query "курица рис" --mode stem --corpus data/sample_corpus.jsonl
```

Тестовый скрипт и CLI поиска на выборке проверены. CLI при отсутствии индекса сохраняет его рядом с данными. Для основного режима лемматизации:

```powershell
python -m pip install -r requirements.txt
python -m rag.search query "курица рис" --corpus data/sample_corpus.jsonl
```

Установка зависимостей при подготовке документации не выполнялась. Без `pymorphy3` режим `lemma` автоматически заменяется на `stem`; фиксируйте фактический режим. Подготовка полного корпуса описана в [RAG](spec/tech/rag.md).

**Веб-приложения пока нет.** Документация сама по себе не закрывает КТ1: нужны запускаемый локальный макет, его файлы в Git, проверенная инструкция запуска и демонстрация сценария. См. [чек-лист](spec/tech/verification.md#контрольная-точка-1).
